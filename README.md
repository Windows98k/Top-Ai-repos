## 详细介绍

### 1. [openclaw/openclaw](https://github.com/openclaw/openclaw)
开源 AI 助手，运行在自己的电脑上而非云端。通过 Gateway 接入常用聊天软件，直接在聊天里指挥它干活。数据存本地，模型可换（Claude、Codex、本地模型）。

### 2. [obra/superpowers](https://github.com/obra/superpowers)
一套 Agent 技能框架和软件开发方法论，让 AI 编程助手更靠谱。

### 3. [NousResearch/hermes-agent](https://github.com/NousResearch/hermes-agent)
Nous Research 出品的个人 AI Agent，强调持续学习和成长。

### 4. [n8n-io/n8n](https://github.com/n8n-io/n8n)
可视化工作流自动化平台，原生支持 AI 能力，400+ 应用集成，可自托管。

### 5. [Significant-Gravitas/AutoGPT](https://github.com/Significant-Gravitas/AutoGPT)
最早出圈的自主 AI Agent 之一，目标是让每个人都能用上 AI。

### 6. [firecrawl/firecrawl](https://github.com/firecrawl/firecrawl)
把任意网页变成干净数据的 API，适合做 AI 应用的数据采集层。

### 7. [f/prompts.chat](https://github.com/f/prompts.chat)
ChatGPT 提示词社区合集，可自托管，提示词不用上传到第三方。

### 8. [AUTOMATIC1111/stable-diffusion-webui](https://github.com/AUTOMATIC1111/stable-diffusion-webui)
Stable Diffusion 最流行的网页操作界面，AI 绘画的标准工具。

### 9. [Snailclimb/JavaGuide](https://github.com/Snailclimb/JavaGuide)
中文后端面试指南，覆盖计算机基础、数据库、分布式、高并发，近年加入 AI 应用开发内容。

### 10. [langgenius/dify](https://github.com/langgenius/dify)
大模型应用开发平台，可视化编排 Agent 工作流和 RAG 流水线，支持云端和自托管。
